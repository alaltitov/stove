# Guition Stove Controller

Сенсорный контроллер печи / термокамеры на базе дисплея **Guition-ESP32-S3-4848S040** и термопары через **MAX6675**.

Проект выполнен по заказу под конкретное устройство и сценарий эксплуатации.  
Репозиторий опубликован в ознакомительных целях.

Протестировано с **ESPHome 2026.3.1**.

---

## 📌 Возможности

- Сенсорный интерфейс на **LVGL**
- Отображение текущей температуры
- Настройка целевой температуры
- Настройка гистерезиса
- Настройка времени выдержки
- Автоматический цикл нагрева:
  - разогрев
  - стабилизация
  - выдержка
  - завершение
- Управление реле нагрева
- Управление реле сигнализации
- Модальное окно завершения цикла
- Wi-Fi индикация
- Web Server
- API
- OTA-обновление прошивки

## 🧠 Алгоритм работы

Контроллер работает по следующему сценарию:

1. Пользователь задаёт:
   - целевую температуру
   - гистерезис
   - время выдержки

2. После нажатия **СТАРТ**:
   - включается цикл
   - контроллер начинает нагрев

3. Когда текущая температура достигает целевой:
   - запускается стадия **стабилизации**
   - температура должна удерживаться на уровне уставки заданное число секунд

4. После успешной стабилизации:
   - стартует таймер выдержки

5. Во время выдержки:
   - нагрев **включается**, если  
     `current <= target - hysteresis`
   - нагрев **выключается**, если  
     `current >= target + hysteresis`

6. После окончания таймера:
   - реле нагрева выключается
   - включается реле сигнализации
   - на экране показывается завершение цикла

## 💾 Какие настройки сохраняются

Сохраняются между перезагрузками (**должна пройти одна минута между сохранением настроек и выключением устройства**):

- целевая температура
- гистерезис
- таймер

Не сохраняются:

- текущее состояние цикла
- текущий остаток таймера
- активность реле
- модальные окна
- внутреннее состояние UI

После перезагрузки устройство стартует в безопасном состоянии:
- нагрев выключен
- сигнализация выключена
- цикл сброшен

## 🖥️ Интерфейс

Проект содержит несколько экранов:

- **Главный экран**
  - текущая температура
  - целевая температура
  - таймер
  - кнопка старт/стоп
  - кнопка настроек

- **Экран редактирования температуры**
  - изменение целевой температуры
  - сохранение изменений

- **Экран таймера**
  - установка часов и минут
  - сохранение

- **Боковая панель настроек**
  - изменение гистерезиса

- **Модальное окно завершения цикла**
  - индикация окончания
  - подтверждение / сброс
